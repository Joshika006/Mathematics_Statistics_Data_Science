# Mathematical & Statistical Analysis for Data Science

## 📌 Project Overview

This project demonstrates the application of fundamental **Mathematics and Statistics concepts** used in Data Science. The analysis is implemented using Python and focuses on Linear Algebra, Probability, and Descriptive Statistics.

The project is developed as part of the **Mathematics and Statistics for Data Science Assignment – 1**.

## 🎯 Objectives

* Apply Linear Algebra concepts using NumPy.
* Perform probability calculations and distribution analysis.
* Apply Bayes' Theorem for conditional probability.
* Analyze datasets using descriptive statistical measures.
* Interpret skewness and kurtosis to understand data distribution.

## 🛠️ Technologies & Libraries

* **Python**
* **NumPy**
* **Pandas**
* **SciPy**
* **Statistics**

## 📂 Project Contents

### Task 1 – Linear Algebra

* Vector Addition
* Vector Subtraction
* Dot Product
* Matrix Addition
* Matrix Multiplication
* Determinant
* Matrix Inverse
* Eigenvalues and Eigenvectors

### Task 2 – Probability Concepts

* Probability of Successful Sales
* Conditional Probability
* Bayes' Theorem
* Binomial Distribution
* Normal Distribution
* Uniform Distribution

### Task 3 – Descriptive Statistics

* Mean
* Median
* Mode
* Range
* Variance
* Standard Deviation
* Skewness
* Kurtosis
* Data Distribution Interpretation

## 📓 Implementation

The complete analysis is implemented in a **Jupyter Notebook**:

`Mathematical_Statistical_Analysis.ipynb`

The notebook contains the Python implementation, calculated results, and interpretations for each task.
